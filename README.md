# The End of Trump? — Geopolitical Investigative Documentary

An automated, broadcast-grade video documentary exploring the political fallout of the 2026 midterms, the escalating naval and military confrontation in the Strait of Hormuz, and threats against Donald Trump.

## Features
- **Visual Storytelling**: 47 curated documentary images + authentic public domain B-roll footages (Persian Gulf aircraft carrier, tanker interdictions, Capitol security).
- **Animated Papercraft Chapter Cards**: Custom animated torn-paper cards with high-voltage yellow (`#FFE600`) highlights and white display typography at 24fps.
- **Narrative Audio**: Deep, authoritative neural voiceover (Christopher Neural) paired with ducked dark cinematic score (`-18dB` ducking) and tactile papercraft SFX.
- **Automated Cloud Rendering**: GitHub Actions pipeline that builds and publishes the full 1080p MP4.

## Cloud Render Workflow
Trigger the GitHub Actions workflow manually via `Actions -> Cloud Render Trump Iran Documentary -> Run workflow` or by pushing commits to `main`.
The rendered video will be uploaded as a GitHub Actions Artifact and published as a GitHub Release asset for direct download.
